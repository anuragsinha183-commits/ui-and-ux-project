# 🍔 QuickBite — Food Delivery Mobile App (UI/UX Case Study)

An end-to-end UI/UX mobile application case study and interactive prototype built to modern design standards (iOS 390px × 844px base grid). 

Repository: [ui-and-ux-project](https://github.com/anuragsinha183-commits/ui-and-ux-project)

---

## 📱 Project Overview
**QuickBite** is designed to provide zero-friction food discovery, transparent ordering, and live delivery tracking with strong visual hierarchy and UX heuristics (Fitts's Law, Jakob's Law, Aesthetic-Usability Effect).

---

## 📂 Deliverables & Tasks

### ✅ Task 1: Wireframing & Low-Fidelity Design
- **`screen-1-home.svg`**: Discovery feed, address bar, search input, promo banner, category chips, food cards, bottom nav.
- **`screen-2-restaurant.svg`**: Storefront hero banner, metadata tags, sticky category filters, dish cards with quantity steppers.
- **`screen-3-cart.svg`**: Cart line items, promo code input, itemized bill breakdown, 1-click payment selector.
- **`screen-4-tracking.svg`**: Live delivery map mockup, real-time 4-step progress line, driver contact card.
- **Documentation**: [`WIREFRAME_DESIGN_SPEC.md`](./WIREFRAME_DESIGN_SPEC.md)
- **Interactive Viewer**: [`index.html`](./index.html)

---

### ✅ Task 2: High-Fidelity UI Design & Design System
- **`hifi-screen-1-home.svg`**: Appetite-stimulating coral/tangerine gradients (`#FF5A26`), 50% discount hero banner, glowing food graphics.
- **`hifi-screen-2-restaurant.svg`**: Dark-mode photography backdrop, bestseller/spicy badges, floating bottom cart CTA.
- **`hifi-screen-3-cart.svg`**: Active promo coupon (`QUICK50` -50%), green discount savings, Apple Pay selector.
- **`hifi-screen-4-tracking.svg`**: Vector road network, real-time courier scooter marker with pulse aura, driver quick actions.
- **Design System Spec**: [`HIFI_DESIGN_SYSTEM.md`](./HIFI_DESIGN_SYSTEM.md)
- **Side-by-Side Comparison**: [`hifi.html`](./hifi.html)

---

### ✅ Task 3: Clickable Interactive Prototype
- **File**: [`prototype.html`](./prototype.html)
- **Features**:
  - Live clickable iPhone shell.
  - Cart quantity adjustments (`+` and `−`) with real-time math calculation for subtotal, promo discount, taxes, and grand total.
  - Screen transitions (Home ➔ Restaurant ➔ Checkout ➔ Live Tracking).
  - Animated courier dispatch marker.
